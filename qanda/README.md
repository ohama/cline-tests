# qanda/

`(Q)` 로 시작한 질문과 그 답변. **한 질문에 한 파일.**

## 왜 남기나

터미널 답변은 스크롤로 사라진다. 이 프로젝트는 이미 확립된 사실을 다시 파낸 적이 여러 번
있고, 더 나쁘게는 **틀린 결론이 대화 안에만 있어서 그대로 이월된 적이 두 번** 있다
(사고 트레이스 누적 여부, `providers.json` 의 `contextWindow` 위치).

`(Q)` 로 표시할 만한 질문은 그 답이 세션보다 오래 남아야 하는 질문이다.

## 규칙

- 파일명 `NNN-짧은-슬러그.md`, 순번대로
- 질문 원문 → 짧은 답 → 근거 순
- **모든 주장에 근거를 붙인다** — 측정값은 실행 디렉터리, 소스 주장은 `file:line`.
  `howto/` 와 같은 기준이다
- **모르는 것은 아는 것만큼 분명히 적는다.** 측정된 것과 추론한 것을 구분한다
- 아래 색인을 갱신한다
