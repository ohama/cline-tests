  fix the cwd handling in the script (this plan may amend

  `EXTRA_ALLOW_PATHS`.

  script so the attempt is unambiguous, then use the one permitted retry.
- `NOT_DENIED`: this would mean the sandbox failed open, which contradicts Phase 3's kernel-level
  evidence. Do NOT paper over it — capture the evidence, run
  `bash phase-03/sandbox/verify_sandbox.sh` for a second opinion, and record the contradiction as
  the plan's finding rather than declaring criterion 3 met.
