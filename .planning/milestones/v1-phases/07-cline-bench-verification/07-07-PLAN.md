<objective>
Apply the fix `07-06` identified, prove it on exactly ONE cline-bench task, and make the proof
machine-checkable — or, if no mechanism works, record that as a terminal outcome and stop.

Purpose: BCH-01 cannot honestly be closed by running more tasks until a task provably reaches
flashnext. This plan is the hinge: everything after it is contingent on which branch it takes.

Output: either `PROOF.md` with a non-empty flashnext log slice and `model_turns > 0`, or
`TERMINAL.md` naming every mechanism tried and why each failed. Plus a new `B11` check in
`verify_bench.sh` so "did a task reach the model" becomes a standing, re-runnable assertion rather
than a claim in prose.

**Exactly one `harbor run` in this plan.** Not two, not "one retry per candidate." If the first
run does not reach the model, the fallback is diagnosis or the terminal branch, not another run —
the same discipline 07-03 applied and the same reason the user chose `stop-at-one`.
</objective>
