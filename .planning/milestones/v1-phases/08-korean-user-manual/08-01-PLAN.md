1. **Six live pids must survive.** At phase start: flashnext `46573`, role-shim `75548`,
   litellm `48525`, kanban `53894`, telegram-connect `99162`, kanban-proxy `19669`. This plan
   deliberately changes the kanban pid — **record the new one**. The other five must be
   byte-identical before and after.
2. **Never `kill`/`pkill`, never `launchctl load|unload|kickstart`.** The only sanctioned
   restart path in this project is `phase-02/infra/restart_service.sh <label> <port|none>` —
   `bootout` is async and that helper already owns the teardown-wait polling.
   Take-down is `launchctl bootout gui/$(id -u)/<label>`.
3. **Host `cline` invocation budget for this phase: 0.** Do not run `cline` for any reason,
   including `--version`/`--help` — every invocation re-triggers the background self-update that
   already drifted the host to 3.0.60. `phase-01/config/check_versions.sh` is BANNED in this
   phase because its Check B invokes the host binary. Read versions from
   `/opt/homebrew/lib/node_modules/{cline,kanban}/package.json` instead. Never `npm install -g`.
   The `kanban` CLI **may** be invoked, but only with `KANBAN_NO_AUTO_UPDATE=1` exported (kanban
   has its OWN separate auto-update gate) and with its version re-checked from package.json
   afterwards.
4. **Never widen the sandbox from this plan.** `EXTRA_ALLOW_PATHS` stays empty,
   `workspace/ALLOWED_REPOS.json` and `workspace/sandbox.sb` stay untouched. Sandbox widening is
   plan 08-04's checkpoint decision and belongs nowhere else.
5. **Never bind port 3000** — a pre-existing public Funnel (`:8443` → `:3000`) points there.
   No mutating `tailscale` command; `tailscale funnel` never; `tailscale serve reset` FORBIDDEN.
6. **Shell facts.** macOS `/bin/bash` is 3.2 — indexed arrays only, no `declare -A`. The
   executing shell is zsh, so wrap anything relying on bash word-splitting in `bash -c '...'`.
   **zsh's `log` builtin shadows `/usr/bin/log`** — always use the absolute path
   `/usr/bin/log stream|show` when capturing sandbox denials (08-RESEARCH.md §A6b-1).
7. **Standing gates, called before and after any live change:**
   `bash phase-01/config/verify_config.sh`,
