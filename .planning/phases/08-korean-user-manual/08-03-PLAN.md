Required content:

1. **기동 — 보통은 아무것도 안 해도 된다.** The services are launchd agents with
   `RunAtLoad: true`; the normal answer to "오늘 아침 뭘 켜야 하나" is "아무것도". Give the
   confirmation command (`bash phase-05/services/verify_services.sh`) and say what a healthy
   result looks like. Point at `docs/manual/00-getting-started.md` for the full service picture.
2. **태스크 실행 — 실제 명령어.** The shipped surface is exactly one interface:
   `phase-04/run_headless.sh [--out-dir <dir>] [--timeout <secs>] [--] <prompt>`. Reproduce the
   env-knob table (`HEADLESS_DRY`, `DRY_FIXTURE`, `RESULTS_ROOT`, `SKIP_SANDBOX_GATE`,
   `WRAPPER_TIMEOUT`) with the warning that `SKIP_SANDBOX_GATE=1` is offline-development-only and
   must never be used on a live run. State that stdout is NDJSON only and diagnostics go to
   stderr, so the wrapper pipes safely. List what lands in the result directory
   (`ndjson.log`, `stderr.log`, `cline_exit.txt`, `config_pre.txt`/`config_post.txt`,
   `sandbox-gate/`, `outcome.json`/`outcome.md`, `workdir.txt`).
3. **결과를 읽는 법.** Reproduce the six-outcome table with exit codes (`success` 0,
   `sandbox_denied` 2, `tty_approval_rejected` 3, `run_aborted` 4, `context_overflow_terminal` 5,
   `other` 6, `crashed` 7, and `1` for wrapper preflight abort) and the operator action for each.
   `crashed` must be marked "판정 불가 — 절대 '차단 성공'으로 보고하지 말 것".
   `context_overflow_terminal` links to `docs/manual/04-32k-operations.md`.
4. **THE CWD RULE.** The process cwd must already be inside `workspace/ALLOWED_REPOS.json`'s
   `repos[]` before the sandbox is entered, or Bun/Node dies during startup with a path-less
   generic error that looks like a sandbox tightening but is not. `cline -c/--cwd` is a separate,
   additional flag and does not substitute for it.
5. **`⚠️ [GAP-READONLY]`** paragraph: the shipped surfaces are `--no-tools` (telegram) and
   `--auto-approve false` (headless wrapper). On 3.0.53 headless, `--auto-approve false` refuses
   every tool call (`tty_approval_rejected`, exit 3) — this is expected behaviour, not a crash.
   The practical meaning for the user: **읽기·대화 전용이며, 원격에서 트리거된 에이전트는 파일을
   수정할 수 없다.** Flipping this posture is a security decision a human must make explicitly
   (`docs/headless-wrapper.md` §4·§8) — the manual does not tell anyone to flip a flag.
6. **Plan/Act.** State the evidence level precisely. `--mode <act|plan>` (default `act`) exists as
   a real CLI option literal in the installed binary, and the internal five-mode tool-permission
   table differs between act and plan only in `enableEditor`. Then the
   **`⚠️ [GAP-PLANMODE]`** paragraph: whether this project's own headless one-shot command exposes
   `--mode` is UNCONFIRMED (a static-analysis limit — the evidence is a `strings` scan, cline was
   never invoked); this project's headless calls have never passed `--mode`, so every run to date
   has been the default act mode; **Plan 모드는 이 프로젝트에서 한 번도 실행된 적이 없다.** Do not
   write that Plan mode works headlessly, and do not write that it does not.
7. **체크포인트 — 두 가지가 있고 서로 다르다.** `⚠️ [GAP-CHECKPOINT-CLINE]`: cline itself has
   session-level file checkpointing (`createCheckpoint`/`restoreCheckpoint`, a `cline-checkpoint-`
   git-ref prefix, same layer as `--id` session resume). The evidence is static string scanning
   only — runtime behaviour (when it fires, whether it is on in headless) is unverified. The OTHER
   checkpoint — kanban's per-task working-tree commit — is a different thing and lives in
   `docs/manual/02-kanban.md`. Say so in one sentence and do not blur them.
8. **`⚠️ [GAP-CLINE-VERSION]`.** The host `cline` has drifted to `3.0.60` from the pinned
   `3.0.53`, and `CLINE_NO_AUTO_UPDATE=1` did not prevent it. Tell the reader to check the actual
   version before trusting anything version-specific here, and to check it by reading
   `/opt/homebrew/lib/node_modules/cline/package.json` — **not** by running `cline --version`,
   because invoking the binary is itself the drift trigger, and **not** by running
   `phase-01/config/check_versions.sh`, whose Check B invokes the host binary. Do not state the
   pin as present fact anywhere in the document.
9. **긴 세션에서 무슨 일이 생기나** — three sentences pointing at
   `docs/manual/04-32k-operations.md` (프리필 대기, 자동 압축과 그때의 지연, 서버 400의 의미).

   even once, so the FIRST launch after injection is the first time the real call line is parsed;
   watch `~/.cline/logs/telegram-connect.log`/`.err` for `unknown option`; and
   `--provider`/`--model` must stay spelled out in full because `cline connect telegram` has no
   `-P` at all and binds `-m` to `--bot-username`. Also: `TELEGRAM_BOT_TOKEN` and
   `TELEGRAM_ALLOWED_USER_ID` must be filled together or the wrapper aborts by design.
   On 승인/거부: the connector runs with `--no-tools`, so **읽기·대화 전용** — an approve/deny
   prompt for a tool action does not arise, because the tool action never happens. Say that
   plainly rather than describing an approval UI nobody can reach.
6. **`⚠️ [GAP-TELEGRAM-INDICATOR]`.** What the user sees during the ~64s wait on Telegram has
   never been observed — the real-token trial was declined. Static reasoning suggests the typing
   indicator will not survive 64s (fired once per message, expired by Telegram after ~5s, no

   The seven-step checklist for running it is
