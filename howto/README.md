## 이 문서들이 지키는 원칙

**HTTP 200 은 증거가 아니다.** 게이트웨이가 요청을 받았다는 뜻이지, 설정이 모델까지
갔다는 뜻이 아니다. 그래서 모든 확인 절차는 **서버 로그의 `prompt_tokens`** 로
역산하는 단계를 포함한다.

이 구분을 안 해서 v1 에서 이틀을 썼다. `providers.json` 에 값이 멀쩡히 적혀 있었고,
CLI 는 200 을 돌려줬고, 그런데 CLI 가 그 칸을 읽지 않고 있었다.

**절대값이 아니라 델타를 본다.** 토큰 절대값은 과거에 이동한 적이 있다
(23/21/51/63 → 13/11/41/53, 원인 미규명). 델타는 비트 단위로 보존됐다.
그래서 판정 기준은 "medium 이면 11" 이 아니라 "미지정보다 2 적다" 이다.

**스크립트는 자기가 틀릴 수 있는 경우를 스스로 신고한다.** 로그를 못 읽으면
중단하고, 요청 귀속이 애매하면 델타를 계산하지 않는다. 조용히 그럴듯한 숫자를
내놓는 것이 가장 나쁘다.
